# 🚀 DevHTML - Landing Page de Aulas e Tutoriais

Uma **Landing Page** moderna e responsiva no estilo *Linktree*, desenvolvida para centralizar links de cursos, vídeos do YouTube, redes sociais e conteúdos em destaque sobre desenvolvimento Front-End.

![Preview da Landing Page](https://raw.githubusercontent.com/github/explore/80688e429a7d4ef2fca1e82350fe8e3517d3494d/topics/html/html.png)

---

## 📌 Sobre o Projeto

Este projeto foi construído durante as aulas de HTML5 e CSS3 com o objetivo de demonstrar a criação de uma página de links interativa, elegante e com efeitos visuais modernos (como gradientes suaves e efeito *glassmorphism*).

### ✨ Funcionalidades
- **Design Responsivo:** Adaptável para telemóveis, tablets e computadores.
- **Banner de Destaque:** Espaço para anúncios de lives, eventos ou novidades.
- **Links Interativos:** Botões estilizados com suporte a ícones e efeitos de *hover*.
- **Grade de Conteúdos:** Secção dedicada para listar tutoriais e vídeos em destaque.
- **Redes Sociais:** Links integrados no rodapé com ícones da comunidade dev.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias web fundamentais:

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, Flexbox, CSS Grid, variáveis e responsividade.
* **Google Fonts (Inter):** Tipografia moderna e legível.
* **FontAwesome:** Ícones vetoriais.

## 📂 Como Executar o Projeto Localmente

1. **Clona o repositório:**
   ```bash
   git clone https://github.com/teu-usuario/landing-page-html.git
   ```

2. **Navega até a pasta do projeto:**
   ```bash
   cd landing-page-html
   ```

3. **Abre o ficheiro no navegador:**
   Basta clicar duas vezes no ficheiro `index.html` ou abri-lo diretamente com a extensão *Live Server* do VS Code.

---

## 🌐 Como Publicar no GitHub Pages

Para disponibilizar esta landing page online através do GitHub Pages:

1. No teu repositório no GitHub, acede a **Settings** (Definições).
2. No menu lateral esquerdo, clica em **Pages**.
3. Em **Build and deployment** > **Branch**, seleciona `main` e clica em **Save**.
4. O GitHub irá gerar o link direto para o teu site em poucos minutos!
